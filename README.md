## 게임 소개

유성이 쏟아지는 마을과 학원을 무대로, 학생회의 일상과 마족과의 싸움이 이어지는 어드벤처입니다.<br>
학생회장이 된 주인공은 동료들과 함께 마을을 지키는 역할을 맡고, 평범한 학교생활과 비밀스러운 임무 사이에서 분주한 나날을 보냅니다.

대화와 장소 선택으로 이야기를 읽는 구간 사이에 전술 배틀이 들어갑니다.<br>
행동 순서가 표시된 타임라인을 보면서 공격과 대기, 동료와의 합동 행동을 조합하는 방식이 특징입니다.

PSP판에는 새로운 캐릭터와 시나리오·CG 등 원작과 구별되는 추가 요소가 있습니다.<br>
호화판에 동봉된 별도 배틀 게임 **STARLIT BRAVE!!**는 이 프로젝트의 대상에 포함하지 않습니다.

### 작품 특징

- 학원 생활과 학생회 활동을 중심으로 한 대화·선택형 어드벤처
- 행동 순서와 합동 공격을 활용하는 타임라인 전술 배틀
- PSP 이식판의 추가 캐릭터·시나리오·이벤트 CG
